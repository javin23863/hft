# Phase 6 Execution Approval Checklist

Must be explicitly approved before any live CEX order routing or on-chain CPFP/RBF broadcast:

- [ ] ISA approved for Phase 6 scope
- [ ] Compliance and legal review complete
- [ ] Dry-run and paper-only validation complete
- [ ] Kill switch and rollback plan documented
- [ ] Operator sign-off recorded

Without all checks complete, Phase 6 remains disabled.
